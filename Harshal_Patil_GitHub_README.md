## Featured Projects

### 1. PrepBro --- Adaptive AI Interview Coach

An LLM-powered interview preparation application that adapts questions
to a candidate's performance and job requirements.

-   Built with **LangChain, Gemini API, FastAPI, Streamlit, and
    Pydantic**.
-   Analyzes job descriptions, generates questions at three difficulty
    levels, and evaluates answers using a four-part rubric.
-   Implements an adaptive question-selection loop using topic
    performance, job importance, and previous attempts.
-   Includes prompt-injection guardrails, session isolation,
    health/readiness checks, and **13 automated offline tests**.

### 2. CiteMind --- AI Research Paper RAG Assistant

A retrieval-augmented generation application that answers questions
about AI/ML research papers and provides paper-and-page citations.

-   Built a RAG pipeline over **16 research papers**, processing **306
    PDF pages into 1,389 chunks**.
-   Uses **LangChain, MiniLM embeddings, FAISS, and Qwen2.5-1.5B** for
    retrieval and local generation.
-   Added relevance-threshold filtering, optional cross-encoder
    reranking, and an insufficient-evidence fallback.
-   Built a Streamlit interface with source/evidence views and validated
    it with **24 passing pytest tests**.

### 3. SupportIQ --- Transformer-Based Support Ticket Classifier

A multi-class NLP model that classifies support tickets by intent.

-   Trained and evaluated a **27-class classifier** on **24,274 cleaned
    examples**, comparing TF-IDF + Logistic Regression with fine-tuned
    DistilBERT.
-   Improved test macro-F1 from **98.88% to 99.64%**.
-   Used deduplication and stratified data splits to help prevent data
    leakage.
-   Added confidence-aware single/batch inference and error analysis;
    measured approximately **15.23 ms CPU inference per ticket**.
